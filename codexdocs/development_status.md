# GitHub Pages版 逆引きマニュアル 開発状況

## 現在の段階

検索・閲覧ページ、公開用データ生成、GitHub Actionsを実装済み。既存サイトは公開済み（ユーザー申告）。PWA設定とアイコンを追加した版の公開は未実施。

仕様は [spec.md](spec.md)、初回設定と使用方法は [README.md](../README.md) を参照。

## 実装済みの内容

- PWAのmanifest、192px・512pxのアイコン、独立ウィンドウ起動設定。オンライン利用とし、Service Workerは使用しない。

- 既存の `cookbooks/` 配下の6文書を変更せず利用する。
- トップページの一覧、ジャンルとアプリの絞り込み、AND部分一致検索、正規化、一致箇所の強調、追加表示。
- ブラウザ内でのMarkdown表示、文書内目次、見出しへの直接移動、履歴と検索条件の復元。
- 参照画像の収集と相対リンク変換、生HTMLの文字列化とサニタイズ。
- 文書の自動検出、検索JSONとハッシュ付き配信ファイルの生成、依存ライブラリのライセンス同梱。
- `master` のpushと手動実行に対応した生成・検証・公開ワークフロー。
- HTTPによるローカル確認用サーバーと生成物のGit除外設定。
- ダークモードを標準とする配色と、見出し・本文のゴシック体への統一。コードは等幅フォントを維持。

## 検証済みの内容

- 自動テスト9件（PWAの相対URL・スコープ・アイコン寸法を含む）: 文書検出、追加・編集・削除、ゼロ件と不足資産の失敗、Markdown解析、検索、強調範囲、相対参照、安全なHTML表示、表・コード・画像の表示。
- `npm run build` による6文書・70項目の生成。
- `npm ci` によるロックファイルからの再インストール成功。依存関係の監査で脆弱性ゼロ件。
- Codex内蔵ブラウザで、複数語検索、コード本文検索、絞り込み、該当なし、文書表示、見出しへの移動、再読み込み、履歴移動を確認。
- ルートと `/software-cookbook/` サブパスの両方で表示を確認。
- 幅360pxでトップページと長いコードを含む文書に、ページ全体の横はみ出しがないことを確認。
- ブラウザ確認中のコンソールにエラー・警告なし。
