## 標準出力

### オブジェクトを見やすく整形して出力するには

標準ライブラリの `pprint.pp()` を使う。辞書やリストなどを、必要に応じて改行・インデントして標準出力する。

```python
from pprint import pp

data = {
    "name": "太郎",
    "scores": {"国語": 80, "数学": 95, "英語": 88},
    "tags": ["Python", "勉強中"],
}

pp(data, indent=2, width=40)
```

- `indent`: インデントの幅。既定値は `1`。
- `width`: 1行の目標幅。既定値は `80`。短いデータは1行にまとまり、長い単一の値などは指定幅を超える場合もある。
- `depth`: 表示する入れ子の深さ。`depth=2` などを指定すると、より深い部分を `...` で省略する。
- `sort_dicts`: 辞書のキーを並べ替えるか。`pp()` は既定で `False`（挿入順）。`pprint.pprint()` は既定で `True`。

自作クラスのインスタンスは、表示が `__repr__()` の実装などに依存する。インスタンス属性の辞書を確認したい場合は `pp(vars(obj))` を使える。ただし、`__dict__` を持たないオブジェクトには使えない。

公式ドキュメント: [pprint — データの整形表示](https://docs.python.org/ja/3/library/pprint.html)
